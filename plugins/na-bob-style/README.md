# na-bob-style

Skill เดียวสำหรับงานเขียนทุกประเภทของ Softlake

- โหมด A กึ่งทางการ (ข้อเสนอทางเทคนิค หนังสือนำส่ง รายงาน อีเมลงาน) ตามสไตล์ Softlake
- โหมด B ทั่วไป และโหมด C ภาษาอังกฤษ
- สคริปต์ `scripts/check_thai.py` ตรวจอักขระต้องห้าม ลำดับสระและวรรณยุกต์ คำสะกดผิด และสำนวน AI
- สคริปต์ `scripts/make_thai_ref.py` สร้าง reference.docx (TH Sarabun New 16 pt, Thai Distributed) สำหรับ pandoc

เรียกใช้ด้วย /na-bob-style หรือสั่งให้เขียน ร่าง หรือเรียบเรียงเอกสาร
